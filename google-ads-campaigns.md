## Campaign Settings (Recommended)

**Budget:** Start at $15-20/day ($450-600/month)
**Bidding:** Manual CPC to start, switch to Target CPA after 30 conversions
**Location:** United States (can narrow to specific metros later)
**Device:** All devices, but monitor mobile vs desktop conversion rates
**Ad schedule:** Monday-Friday 7am-7pm (business hours + buffer)
**Conversion tracking:** Set up Google Ads conversion tracking on the intake form thank-you page

**Negative keywords (add these immediately):**
- free
- login
- sign in
- admin console
- support number
- google support
- careers
- jobs
- tutorial (use with caution — some tutorial seekers convert)
- certification
- exam
- salary

## How to Set Up in Google Ads

1. Go to ads.google.com and create a new campaign
2. Choose "Leads" as your goal
3. Select "Search" campaign type
4. Set budget to $15-20/day
5. Target: United States
6. Create ad groups matching the groups above
7. Add keywords as "phrase match" (use quotes) — NOT broad match
8. Add all negative keywords
9. Set landing page to: https://stevesitpro.com/get-started/
10. Enable conversion tracking on the intake form submission
11. Let it run 2 weeks before making changes — Google needs data
12. After 2 weeks: pause keywords with high spend but no conversions, increase budget on winners
